# Contributing

Contributions that improve correctness, reproducibility, documentation, or
support for additional activation functions are welcome.

1. Create the environment from `environment.yml`.
2. Make focused changes on a feature branch.
3. Run `python -m unittest discover -s tests -v`.
4. Do not commit generated CSV, plot, log, or result directories.
5. Open a pull request describing the motivation and validation performed.

For vulnerabilities or exposed credentials, follow [SECURITY.md](SECURITY.md)
instead of opening a public issue.
